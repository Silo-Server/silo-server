# DB-backed pins. CI runs them against a freshly migrated Postgres; locally,
# `make test-db-pins` runs them against the database named by
# SILO_TEST_DATABASE_URL.
#
# One test per line: the package directory, then the top-level test name.
# Each test asserts how many statements, rows or resolver calls an operation
# costs, that a query plan uses its index, the result parity that such a
# budget relies on, or behavior that only a migrated schema can show. The
# runner (scripts/ci/dbpins) fails when a listed test is missing, skipped or
# failing, so a pin cannot switch itself off by skipping on an unset database
# URL or an unmigrated schema.
#
# Add a pin in the same change that sets its budget or adds the test. It must
# pass on a freshly migrated database without skipping.
